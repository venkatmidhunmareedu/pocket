# Session handoffs
Short notes (max 20 lines each) so a new chat can pick up where the last one stopped.
- `LATEST.md` — the most recent handoff. Read this first.
- `sessions/NN-YYYY-MM-DD.md` — one file per session, oldest to newest.
Say **"session handoff"** at the end of a chat to write one; say **"session resume"** at the start of a new chat to load it.
Project facts (architecture, commands) live in `../CLAUDE.md`, not here.
